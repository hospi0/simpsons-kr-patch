### 언어 청크(0x0001800E) 내부 — 실측 확정

```
u8 + 이름    "exportart\frontend\scrooby\resource\txtbible\srr2<언어>"  (NUL 패딩)
u8           언어 코드 ('E')
u32 n        항목 수 1629
u32 ?        0x2DA027 (마지막 키 근처 값 — 미규명)
u32 blen     문자열 영역 바이트 수
u32 key[n]   «정렬된» 키 해시 (오름차순)
u32 off[n]   문자열 영역 내 바이트 오프셋
<blen 바이트>  ★★★ **UTF-16LE, NUL 종단**
```

→ **문자열이 이미 UTF-16 이라 한글을 «인코딩 개조 없이» 넣을 수 있다.**
→ 항목별 길이 제한도 없다(오프셋 표를 다시 쓰면 된다). 청크 크기만 갱신하면 된다.

도구 `tools/txtbible.py` — 요약 / `E` 지정 시 `키<TAB>문자열` 전량 덤프.
영문 전량은 `work/text_en.tsv` (1,629줄).

## 3. ★★ 키 «이름»이 평문으로 들어 있다

UI 정의 파일(`frontend.p3d` 등)의 청크 **`0x0001800B`** 가 `srr2 / <키이름>` 쌍이다.

```
srr2 / MISSION_TITLE_L1_M1
srr2 / MISSION_TITLE_L2_M3
…  frontend.p3d 에만 1,021개
```

→ 키 해시 ↔ 사람이 읽는 이름을 이어 붙일 수 있다. 번역표 만들 때 큰 도움.

| ID | 정체 |

| `0x00018002` | 페이지 (`3dFEGags.pag`) |

| `0x00018100` | 이미지 참조 |

## 5. ⏳ 아직 못 찾은 것 — 폰트

UI 가 참조하는 폰트는 5종이다.

```
font0_16 · font0_24 · font1_14 · font2_12 · font3_12   →  "fonts\fontX_YY.p3d"
```

⛔ **FST 에 `fonts/` 디렉터리가 없다.** 참조만 있고 실물을 아직 못 찾았다.
후보: ① `.rcf` 아카이브 안 ② 참조하는 `.p3d` 안에 인라인 ③ DOL 안.

`.rcf` = `RADCORE CEMENT LIBRARY`, 버전 `0x01020101`, 디렉터리가 `0x800` 부터
(BE u32 = 파일 수, `scripts.rcf` 는 116개). 항목 구조는 아직 미확정.

**폰트는 한글화의 성패를 가른다** — 한글 2,350자를 담을 자리와 형식을 확인해야 한다.

## 7. 도구

```
python tools/gcfst.py   <iso>                          # FST 목록
python tools/gcfst.py   <iso> --get <경로> <출력>       # 파일 추출
python tools/p3d.py     <p3d>                          # Pure3D 청크 트리
python tools/txtbible.py <srr2.p3d> [언어코드]          # 텍스트 바이블 판독
python tools/findstr.py <iso> <문자열…>                 # ISO 전체 검색 + FST 위치
```
